GitHub Repo Setup — For Ayesha

Follow these steps on github.com to create the repo and share access.

⚠️ Security note: Never share your GitHub password with anyone. These instructions use a Personal Access Token instead — it's safer, limited, and you can revoke it anytime.
1
Create a New Repository
  1. Go to github.com and sign in
  2. Click the + icon (top-right corner) → "New repository"
  3. Fill in:
    • Repository name: pak-tele-health
    • Description: Rural telehealth MVP — healthcare worker collects, doctor reviews
    • Visibility: Choose Private (or Public, your choice)
    • DO NOT check "Add a README file"
    • DO NOT add .gitignore or license (we already have them in the code)
  4. Click "Create repository"
After creating, you'll see a page with setup instructions. Copy the repo URL — it looks like:
https://github.com/ayeshashafqat01/pak-tele-health.git (Your actual username may be different — copy whatever GitHub shows.)
2
Create a Personal Access Token (PAT)

This token lets someone push code to your repo without needing your password.

  1. Go to: github.com/settings/tokens
    (Or: Click your profile picture → Settings → Developer settings → Personal access tokens → Fine-grained tokens)
  2. Click "Generate new token"
  3. Fill in:
    • Token name: pak-tele-health-push
    • Expiration: 30 days (or 7 days if you want shorter)
    • Repository access: Select "Only select repositories" → choose pak-tele-health
  4. Under "Permissions" → Repository permissions:
    • Contents: set to Read and write
    • Everything else can stay as "No access"
  5. Click "Generate token"
⚠️ The token is shown ONLY ONCE. Copy it immediately and send it to the person who will push the code. It looks like:
github_pat_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
3
Share These Two Things

Send these two things to the person pushing the code:

1. Repo URL https://github.com/YOUR_USERNAME/pak-tele-health.git
2. Access Token github_pat_xxxxxxxx...
That's it! The other person will use these to push the code. You don't need to do anything else.
4
What Happens After Code is Pushed

Once the code is pushed to your repo:

  1. Go to github.com/YOUR_USERNAME/pak-tele-health
  2. You'll see all the project files, commits, and documentation
  3. The README.md will show project description and setup instructions
  4. setup-guide.html has detailed setup instructions for anyone cloning the repo
  5. testing-guide.html has step-by-step testing instructions
✅ After the push is done, you can revoke the token for safety:
Go to Settings → Tokens → click the token → Delete
5
If You Want to Run the Project Yourself

After the code is on GitHub, you can clone and run it on your own machine:

git clone https://github.com/YOUR_USERNAME/pak-tele-health.git

Then open setup-guide.html in the repo — it has complete step-by-step instructions for installing Node.js, MySQL, and running the app.

Or just ask Claude: "I cloned the pak-tele-health repo, help me set it up and run it" — Claude can read the project files and guide you.
