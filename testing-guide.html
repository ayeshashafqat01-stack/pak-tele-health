  1. Go to dashboard
  2. KPI: "Pending sync" shows 2 (or more) ☐
  3. Pending sync table shows actual records with: type, saved time, attempts, status ☐

C) Verify IndexedDB Storage

  1. Open browser DevTools → Application tab → IndexedDB
  2. Find database: pak-tele-health-offline ☐
  3. Table: mutations — your queued records are here ☐
  4. Each record has: id, type, endpoint, body (JSON), idempotencyKey, status ☐

D) Go Online & Sync

  1. Click Online in header
  2. Sync starts: status changes PENDING → SYNCING → SYNCED ☐
  3. Dashboard pending count goes to 0 ☐
  4. IndexedDB: synced records get cleaned up after ~3 seconds ☐
  5. Refresh dashboard: newly registered patient appears with real code ☐

E) Auto-Detection (without simulator)

To test real network detection:

  1. Turn off WiFi / disconnect ethernet on your computer
  2. App should detect offline automatically within seconds ☐
  3. Turn WiFi back on
  4. App detects online, starts syncing queued items ☐
How it works:
1. window.offline/online events — instant detection
2. /api/health/live ping every 30 seconds — catches "connected but no internet"
3. Forms save to IndexedDB via Dexie when offline
4. Sync coordinator sends in dependency order (patient before observation)
5. Idempotency keys prevent duplicates on retry

API Endpoint Tests (Terminal)

Run these in a terminal to test API directly:

Health Checks (no auth needed)

curl http://localhost:3000/api/health/live
# → {"status":"ok"}

curl http://localhost:3000/api/health/ready
# → {"status":"ready","db":"connected"}

Unauthenticated Access (should fail)

curl http://localhost:3000/api/v1/patients
# → Redirects to /login (302)

Authenticated API Test

To test with curl, you need the session cookie. Easiest way:

  1. Login in browser
  2. Open DevTools → Application → Cookies → localhost
  3. Copy the value of authjs.session-token
  4. Use in curl:
TOKEN="paste-your-session-token-here"

# List patients
curl -H "Cookie: authjs.session-token=$TOKEN" \
  http://localhost:3000/api/v1/patients?select=id,code,name,pathway

# Get single patient
curl -H "Cookie: authjs.session-token=$TOKEN" \
  http://localhost:3000/api/v1/patients/PATIENT_ID_HERE

# HW Dashboard
curl -H "Cookie: authjs.session-token=$TOKEN" \
  http://localhost:3000/api/v1/hw/dashboard

# List symptoms
curl -H "Cookie: authjs.session-token=$TOKEN" \
  http://localhost:3000/api/v1/symptoms

# List destination facilities
curl -H "Cookie: authjs.session-token=$TOKEN" \
  "http://localhost:3000/api/v1/facilities?type=destination"
